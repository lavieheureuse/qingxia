# 拾影 · 抖音视频下载

一个保持 800 × 600 紧凑界面的 uTools 插件：粘贴抖音分享文本 → 解析真实信息 → 确认后下载到本地。

**版本：0.2.0。交付的是可导入开发工程的源码 ZIP，不是可直接双击安装的 `.upx`。**

## 0.2.0 的工作方式

- 先尝试普通公开请求；需要网页辅助时，按需启动本机 Chrome / Edge 的**标准 headless 模式**，读取精确目标作品的公开播放数据。
- 网页辅助不再依赖 uTools 的隐藏 uBrowser 队列。每次需要辅助的解析创建本插件拥有的独立引擎进程；读取完成、失败或取消后执行退出清理，不保留常驻解析浏览器。
- 使用插件数据目录内的**专用 profile**，不会读取、复制或连接你平时 Chrome / Edge 的默认资料，也不会沿用旧版 uTools uBrowser 的会话。
- **临时的是进程，不是每次删除登录资料。** 专用 profile 保留本插件的浏览器会话；只有显式点击“打开抖音 / 登录”才会启动可见网页。完成必要的登录或人工验证后，请关闭该窗口，再回到插件点击解析。
- 这**不是完全 browserless** 的方案，也不意味着绕过验证码、登录或访问限制。解析失败不会自动改成可见弹窗，不承诺所有作品都能成功。

### 已实现的功能

- 处理单个公开视频的完整分享文本、短链、标准视频链接和 `modal_id` 链接。
- 显示真实标题、作者、封面、时长和可用清晰度；没有取得的数据不编造，不拿推荐视频替换目标。
- 流式下载 MP4 / WebM，显示真实接收字节、速度与可用百分比；支持停止、失败提示、重名保护。
- 自选本地保存目录，默认使用系统下载目录下的“拾影”；本地记录可打开文件或定位目录，清空记录不删除视频。
- 可粘贴多个带 `http` 或 `https` 的作品链接，点击“批量下载”后逐个解析和下载；逐条显示结果，失败不影响后续任务，停止后已保存的文件会保留。单次最多 100 个链接，相同链接自动去重。
- 保留已确认的灰绿 / 森林绿界面、下载与记录两个页签及键盘操作。解析成功不会自动下载。

## 环境要求与安装

- **本机已安装 Chrome 或 Edge**，且位于实现支持的常见安装位置；不下载或捆绑浏览器。Windows 为本次实际验证环境，macOS / Linux 尚未实机验收。
- **插件运行环境的 Node.js 需为 16+**；实测 uTools 7.8.0 内置 Electron 22 / Node.js 16.17.1，本插件按其能力编写。本次独立产品代码验证使用 Windows、Chrome 156 与 Node.js 24。
- 无 npm 运行时依赖，无需 `npm install`，也不需要 Python、FFmpeg 或第三方解析服务。

安装步骤：

1. 解压源码 ZIP，保留完整的 `douyin-utools` 文件夹。不要只拷贝 HTML，也不要把 ZIP 改名为 `.upx`。
2. 在 uTools 应用市场安装并打开 **uTools 开发者工具**。
3. 使用本地项目的新建 / 导入入口选择 [plugin.json](<plugin.json>)；如要求选择工程目录，则选择包含它的 `douyin-utools`。按工具要求填写名称“拾影”、简介及开发者信息。
4. 点击 **安装（开发模式）**，再点击 **打开**。
5. 在 uTools 搜索框输入 **拾影**、**抖音下载** 或 **douyin** 进入插件。
6. 如需可双击安装的分发包，使用 uTools 开发者工具的打包 / 导出功能生成真正的 `.upx`。

官方流程参考：[创建插件](https://www.u-tools.cn/docs/getting-started/create-plugin.html)、[运行与调试](https://www.u-tools.cn/docs/getting-started/run-debug.html)。当前文档主要面向 8.0+，旧版开发者工具的按钮名称可能不同。

### 从旧版更新

1. 退出当前插件，用 0.2.0 源码包**完整覆盖原工程**，不要只替换 HTML。
2. 在开发者工具中对原插件重新安装 / 重载；保持原工程入口，不必为了更新而卸载、清理数据或创建同名插件。
3. 必须让插件进程重新加载，避免仅刷新页面仍复用旧的 CommonJS 模块缓存。
4. 重新进入，确认底部版本为 `v0.2.0`，再解析目标链接。
5. **旧版已经在 uTools 网页登录，不等于新版独立 Chrome / Edge profile 已登录。** 但也不需要先要求你重新登录：本次目标作品已在未导入 Cookie 的匿名专用会话中成功解析。只有实际遇到登录或人工验证需求时，才手动登录一次、关闭窗口后重试。

## 使用

1. 点击“更改目录”，选择本地可写文件夹。
2. 粘贴完整分享文本，点击“解析视频”，或按 `Ctrl + Enter`。
3. 等待普通请求或按需 headless 辅助完成；正常解析不应要求每次打开可见网页。不要同时保留本插件的手动登录窗口占用专用 profile。
4. 核对标题、作者等真实信息，再点击“下载视频”。
5. 等待真实进度完成，使用“打开视频”或“在文件夹中显示”。
6. 如需取消，点击“停止”。如果文件已完成提交落盘，最终状态保留“已保存”，不会把已保存文件误报为取消；本地记录写入失败时会保留成功及警告。

从 uTools 的分享文本匹配入口进入，只会填入文本，不会自动解析、读取剪贴板或下载。只有点击“粘贴”才读取剪贴板。等待网页数据不显示假百分比。

临时隐藏 uTools 不主动取消任务。在支持 `utools.onPluginExit` 的轻匣中，插件真正关闭或轻匣退出时会等待引擎清理与任务取消；旧宿主卸载页面时尝试执行清理。关闭 / 卸载 / 强制结束插件可能中断任务。**不能保证操作系统强杀、插件崩溃、断电等异常情况下必定完成进程清理。**

### 什么时候需要登录？

- 当前已验证的目标作品可匿名解析，不以“未取得播放数据”直接证明你未登录。
- 平台实际要求登录或人工验证时，点击“打开抖音 / 登录”；这是唯一允许启动可见网页的操作，不自动解析或下载，也不代做验证。
- 登录完成后**关闭该专用浏览器窗口**再解析。登录窗口与 headless 解析共用本插件自己的 profile，不支持并发占用；窗口未关闭时会提示 `BUSY`。
- 新专用 profile 与旧版 uTools 网页、你日常浏览器、手机抖音的会话均不同。实现不导出 Cookie、不读取默认 profile，也不把浏览器 Cookie 注入 Node 下载请求。
- 若出现 `ENGINE_NOT_FOUND`，请安装受支持的 Chrome / Edge；`ENGINE_NOT_READY` 表示本次没有读到可确认的目标公开播放地址，并不等同于账号未登录。
- 若出现 `ENGINE_CLEANUP_FAILED`，实现不能确认自有引擎已退出，会阻止再次启动。请退出插件并检查本插件专用 profile 对应的进程，不要批量结束自己的其他浏览器窗口。

## 范围与限制

- 只下载自己拥有或已获授权的公开视频。不支持私密、好友限定、付费、DRM、图集、直播、通过主页自动批量获取作品、音频单独下载或分段流合并。
- 不代做验证码、不生成反爬签名、不导出 Cookie、不修改水印播放地址，不保证所有视频都无水印。
- 页面结构、地区、网络、CDN 签名和风控可能变化。403 / 链接失效时先重新解析，不承诺所有作品持续可用。
- 网页辅助必须精确匹配作品 ID 的公开播放数据，找不到就明确失败，不使用推荐视频、截图或假数据充数。
- 下载保留原始媒体、不转码；部分 4K 媒体采用 HEVC/H.265，播放器需有对应解码能力。插件本身不依赖 FFmpeg。
- 默认单文件上限为 2 GiB；暂不支持暂停、断点续传或多任务队列。
- 最终文件以原子硬链接发布，避免覆盖同名文件。请使用支持硬链接的本地 NTFS / APFS / ext4 等文件系统；FAT / exFAT / 部分网络盘可能明确报错。
- 手动移动文件后，记录路径不会自动更新；封面签名过期不影响已保存视频。
- 浏览器直接打开 [index.html](<index.html>) 仅预览界面，没有宿主下载能力；`?design=1` 仅供静态设计审阅。

## 隐私与结构

- 设置及历史在 uTools 的 `userData/shiying-douyin-plugin`；宿主未给出可用路径时回退到用户主目录的 `.config/shiying-douyin-plugin`。
- 专用浏览器 profile 位于上述插件数据目录的 `transient-browser/session`。浏览器在该目录管理自己的会话资料，**不是插件没有任何 Cookie 存储**；产品代码不读取、复制、导出这些 Cookie，也不访问日常浏览器的默认 profile。
- 不接入分析统计、不上传下载记录、不保存账号密码。媒体签名地址只留在任务内存，不传给前端、不写入下载历史。
- 源码包不包含登录资料、Cookie、媒体签名、真实下载样本或本机路径。
- 前端只有窄接口，不能提交任意下载 URL 或打开任意文件；下载及重定向验证 HTTPS / 官方域名。网页捕获只投影精确作品的有限公开字段，不展开账号状态或全局 store。
- 引擎通过本机回环调试连接控制插件自己启动的进程，使用带所有权标识与锁的专用 profile，不连接其他浏览器的调试端口。标准 headless 参数不代表隐身、反检测或免受平台限制。

主要文件：[前端](<app.js>)、[预加载](<preload.js>)、[临时引擎编排](<core/transient.cjs>)、[自有进程驱动](<core/transient-driver.cjs>)、[回环协议连接](<core/cdp-socket.cjs>)、[公开数据捕获](<core/browser.cjs>)、[解析](<core/parse.cjs>)、[服务桥接](<core/service.cjs>)、[下载](<core/download.cjs>)、[存储](<core/storage.cjs>)。

这是独立的 JavaScript/uTools 实现，不依赖原 Python CLI 的 Argus 流程，不打包原仓库或第三方下载程序。
