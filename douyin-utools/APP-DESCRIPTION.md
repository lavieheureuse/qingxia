# 拾影 · 抖音视频下载 — 应用描述

## 一句话简介（市场卡片 / plugin.json description）

粘贴抖音视频链接，先看预览，再决定是否下载到本地。

## 详细描述（插件市场详情页）

拾影是一个轻量的抖音公开视频下载工具。把抖音分享文本、短链接或作品链接粘贴进来，它会解析出这条视频的封面、标题、作者和清晰度；确认无误后再点下载，文件会保存到你选择的文件夹。

**主要功能**

- 支持 `v.douyin.com` 短链、`douyin.com/video/…` 作品链接，以及整段分享文案（自动提取其中的链接）
- 单条视频先预览确认再下载；批量下载须主动点击按钮，不会粘贴后自动下载
- 支持粘贴多个作品链接，点击“批量下载”后逐个解析下载，并显示每条结果
- 支持输入用户主页分享链接和起止序号，依次下载获取到的公开作品
- 可自选保存目录；重名不覆盖，自动区分文件名
- 下载记录保存在本地，可打开、定位、清空（清空记录不会删除视频）
- `Ctrl + Enter` 快速解析

**隐私与运行方式**

拾影不使用第三方解析服务，也不读取或复制你日常浏览器的个人资料。需要网页辅助时，它按需启动本机已安装的 Chrome / Edge 的标准无头模式，读完目标数据立即退出，不会留下常驻后台浏览器；使用的是插件自己隔离的独立配置目录。如果你确实需要登录，只有主动点击「打开抖音 / 登录」时才会出现一个可见窗口，登录后把这个窗口关掉，再回来解析即可。

**适用与限制**

- 支持公开可访问的视频作品链接；私密、好友可见、付费、DRM、图集和直播不支持。主页作品列表受登录、风控及页面变化影响
- 不做验证码代答、不伪造签名；平台页面或风控变化时，不保证所有链接都能解析成功
- 请只下载自己拥有或已获授权的视频

**运行要求**：uTools 7.8 及以上；本机已安装 Chrome 或 Edge。
