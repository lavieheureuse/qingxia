# 交付验证记录

日期：2026-11-04；版本：0.2.0。本文将**独立产品代码实测、隔离自动化和真实 uTools 宿主验收**分开记录，不能互相替代。

## 当前结论

0.2.0 改为按需启动本机 Chrome / Edge 的标准 headless 引擎，使用本插件独立 profile，解析结束或取消后退出；正常解析不依赖 uTools 隐藏 uBrowser，也不自动弹出可见网页。只有显式手动登录使用可见窗口，且必须关窗后再解析。

**已有证据：** 在本机 uTools 7.8.0 自带的运行时（Electron 22.3.27 / Node.js 16.17.1）下执行交付产品代码，针对同一个目标作品的标准链接、短链均成功，交付下载器保存了真实 13,626,010 字节 MP4；取消返回 `CANCELLED`，随后按本产品专用 profile 限定检查，匹配进程数为 0。没有导入 Cookie。同一环境下另一个**不同作品**也精确解析成功。全部 395 项自动化测试通过（Node.js 24 执行）。

**尚不能宣布：** 插件窗口内的人工点击流程（预览、按钮、历史、登录、临时隐藏/关闭）仍由使用者在真实宿主中逐项确认；本版已修正宿主内置 Node 16 被误判为“引擎不可用”的门槛问题，但宿主 UI 逐项验收表仍需实测填写。

## 3. 生命周期、会话与隐私边界

- 普通公开请求可直接成功；需要网页辅助时才为该次解析启动标准 headless Chrome / Edge。完成、失败、取消都走自有引擎退出清理，不保留常驻解析进程。
- 专用 profile 在插件数据目录的 `transient-browser/session`。**进程按需退出，profile 会话资料保留。** 不能写成“每次解析完全删除浏览器资料”，也不能把专用 profile 说成默认浏览器资料。
- 只控制自己启动、带所有权标识的进程和 profile，不读取 / 复制默认 profile，不连接其他浏览器调试端口，不读取 / 导出 Cookie，不注入 Cookie 到 Node 下载请求。
- 浏览器自身可在专用 profile 保存登录会话；因此“不导出 Cookie”不等于“磁盘上没有任何 Cookie”。源码包不含该 profile。
- 新版独立 Chrome / Edge 会话与旧版 uTools uBrowser 会话不同。旧版已登录不能证明新版已登录，但当前样本匿名成功，不能在没有证据时要求用户先重新登录。
- 确有登录 / 人工验证需求时，只由用户显式打开可见登录窗口。完成后关窗再试；窗口未退出时不允许另一次解析争用同一 profile。该真实手动流程仍待验收。
- 正常页面卸载尝试终止自有进程并取消任务。**不保证操作系统强杀、插件崩溃、断电等情况下清理必定执行或立即结束全部子进程。** 无法确认正常退出时应报错并阻止重入，不能把异常清理当作已通过。
- 不是完全 browserless，也不是反检测浏览器；不使用登录绕过、验证码代答或签名生成，不保证所有作品持续成功。

宿主操作建议：

1. 按 [更新指南](<README.md#从旧版更新>) 完整覆盖并重载原插件，核对 `v0.2.0`。旧版浏览器登录不必先退出，也不要以丢弃用户原数据作为更新步骤。
2. 先直接解析当前已知匿名可用的目标，核对真实预览；关闭旧的辅助窗口，再重复一次。正常解析不应自动可见导航。
3. 换一个**不同作品 ID**的公开链接，分别验证准确预览及下载，不能只把同一目标换成短链。
4. 下载到本地可写目录，检查文件与真实字节进度，再测试取消、同名保护及历史操作。
5. 如确实需要登录，由用户点击“打开抖音 / 登录”处理，**关闭新专用窗口**后重试。失败时记录安全错误码，不能将“没数据”直接归因于未登录。
6. 检查进程时只限定本产品专用 profile，不批量结束日常浏览器，不声称崩溃或 OS 强杀场景已经覆盖。

## 5. 未覆盖场景与历史证据

- macOS / Linux、未安装 Chrome / Edge、非常规安装位置、不同宿主内置 Node 版本、真实人工验证码、多地区 / 风控 / 无网络、外置 FAT / exFAT / 网络盘仍需按环境实测。

- 历史独立 Chromium / Node 曾完整下载 [作品 `7604129988555574538`](https://www.douyin.com/video/7604129988555574538)（186,865,391 字节）及 [另一公开分享](https://v.douyin.com/omcSav7QtFs/) 对应的 `7678695071319841723`（59,880,619 字节），并做过容器 / 轨道检查。这属于旧路径的历史记录，**不能计作本版已验证第二个不同作品**，也不能代替本版手动登录测试。
- 0.1.x 的 uBrowser 会话复用、隐藏队列与原生 `wait` 行为不再是 0.2.0 默认辅助路径。保留相关源码 / 回归不代表当前交付依赖或已经验证旧宿主行为。
