# uPrint 批量打印 · uTools 插件

批量打印 PDF / Word（`.docx`）/ 图片，支持 **纸张大小、页边距、页面方向、份数、页码范围、缩放** 等设置。

## 功能

- 📄 批量添加 PDF / Word（`.docx`）/ 图片（按钮 / 文件夹 / 拖拽 / 在 uTools 主框选中文件后回车进入）
- 📐 纸张大小：A3 / A4 / A5 / B5 / Letter / 自定义尺寸（毫米）
- 📏 页边距：上 / 下 / 左 / 右 独立设置（毫米），预览区实时显示
- 🧭 页面方向：纵向 / 横向
- 🖨️ 选择打印机、打印份数、彩色/黑白、页码范围、缩放比例
- ⚡ 静默批量打印（不弹打印对话框，逐个自动发送）
- 💾 设置自动保存

## 安装（开发者模式）

1. 打开 uTools → 右上角「设置」→「开发者工具」→「创建插件」
2. 选择本文件夹中的 `plugin.json`（或把整个文件夹拖入）
3. 插件即出现在 uTools 中，输入 `批量打印` / `uPrint` / `打印` 即可呼出

> 分发时把整个文件夹打成 zip：uTools 开发者工具里选「打包」即可生成 `.upx`。

## 打印引擎说明（重要）

在支持 `utools.onPluginExit` 的轻匣中，插件真正关闭或轻匣退出时会停止它正在运行的打印辅助程序，并停止继续提交队列中的文件；开启“后台运行”后关闭窗口仅隐藏页面。已交给 Windows 打印队列或其他关联程序的任务不由插件控制，可能继续打印，需要在系统打印队列中处理。

插件按可用性自动选择引擎：

| 引擎 | 支持格式 | 纸张 | 页边距 | 方向 | 份数 | 页码范围 | 静默 |
|------|---------|------|--------|------|------|---------|------|
| **Windows 原生引擎**（首选） | PDF / 图片 | ✅ | ✅ | ✅ | ✅ | ✅（PDF） | ✅ |
| **系统关联程序**（兜底） | PDF / Word（`.docx`） | 取决于程序 | 取决于程序 | 取决于程序 | 取决于程序 | 取决于程序 | 尝试按所选打印机直送 |
| **系统打印对话框**（最后兜底） | PDF / 图片 | 在窗口中设置 | 在窗口中设置 | 在窗口中设置 | 在窗口中设置 | 在窗口中设置 | ❌ |

- **PDF / 图片**：Windows 10/11 使用系统自带的 `Windows.Data.Pdf` / `System.Drawing.Printing` 直接发送到右侧下拉框选中的打印机，无需安装或关联第三方阅读器。
- **Word（`.docx`）**：调用系统关联的 Word/WPS，并将右侧下拉框所选的打印机传入；关联程序不支持时会在文件行提示失败。

## 支持的文件

- ✅ PDF（`.pdf`）
- ✅ Word 文档（`.docx`，需系统已安装并关联 Word 或 WPS）
- ✅ 图片（`.png .jpg .jpeg .bmp .gif .webp .tif .tiff`）
- ❌ 其他 Office 文档（`.doc/.xls/.xlsx/.ppt/.pptx` 等）：请先用 Word/WPS「另存为 PDF」再批量打印

## 页码范围怎么填

- 选「全部」：打印所有页
- 选「指定」：填 **从 1 开始** 的页码，如 `1-3` 表示前 3 页，`1-3,5,8` 表示第 1 到 3 页、第 5 页、第 8 页
- 仅对 PDF 生效，图片忽略此项

## 常见问题

- **PDF 没有直接发送到所选打印机**：说明当前默认 PDF 阅读器未提供 `PrintTo` 能力，插件会改为弹出系统打印窗口；这是 Windows 对不同 PDF 阅读器的能力差异。
- **PDF 页边距不生效**：PDF 由默认阅读器或 SumatraPDF 控制，插件无法统一注入页边距；请在系统打印窗口或源 PDF 中设置。
- **想调默认打印机**：右侧「打印机」下拉选择，会自动保存。
