# 应用代理

在轻匣中选择“添加工具”，导入本目录的 `plugin.json`。插件自带 Windows x64 的 ProxyBridge 4.3.0 命令行核心和 WinDivert 驱动，不需要安装 ProxyBridge 图形程序。

添加已有的 SOCKS5 或 HTTP 代理服务器，添加应用规则后启动。启动和停止可能要求 Windows 管理员授权。代理核心与原版 ProxyBridge 不能同时运行；使用插件前应先退出原版软件。规则修改需要先停止代理。

启用插件内的“插件启动时自动启动代理”后，每次插件加载时会尝试启动代理。若要随轻匣启动，还需在轻匣的插件设置中开启“随轻匣启动”。

使用支持插件退出回调的轻匣时，未开启“后台运行”则关闭插件时停止代理；开启后关闭窗口只隐藏，代理继续运行。退出轻匣时代理会停止，可能需要管理员授权。如果停止失败，轻匣会提示并保持运行。旧版轻匣不支持自动清理，关闭前需要手动停止代理。界面显示进程状态，不保证代理服务器可用；请通过目标应用验证实际网络流量。未匹配规则的连接直接连接。运行时临时配置包含代理凭据，停止或发现进程退出后会删除；异常退出可能留下该文件。持久配置中的密码使用当前 Windows 账户加密。

请先验证插件及现有配置，再考虑卸载原版 ProxyBridge。当前版本不自动迁移原版配置。

核心组件来自 [ProxyBridge 4.3.0 Windows](https://github.com/InterceptSuite/ProxyBridge/releases/tag/v4.3.0_Windows)；授权文件位于 `bin` 目录。
