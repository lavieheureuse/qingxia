# JSON 工坊

轻匣本地插件，零外部网络依赖，默认空白启动，打开即用。提供 **JSON 格式化**、**图片转 JSON** 与 **JSON 转图片** 三项核心能力，并内置浅色森系与深色松林双主题；所有代码输入与输出区均支持自动换行与不带入复制的行号显示。

## 功能概览

1. **JSON 格式化**
   - 支持格式化（`Ctrl+Enter`）、单行压缩（`Ctrl+Shift+M`）、键名递归排序、字符串转义/去转义，以及 `2 空格` / `4 空格` / `Tab` 缩进切换。
   - 支持代码高亮视图与可折叠树形检视（点击节点可一键复制 JSONPath）。
   - 解析报错时精确提示行号、列号并支持一键定位到出错行；支持拖入本地 `.json` / `.txt` 文件，也可点击「载入示例」快速体验。

2. **图片转 JSON**
   - 支持点击选择、文件拖拽、`Ctrl+V` 直接粘贴剪贴板图片（支持多图）及内置快速示例图。
   - **Base64 封装**：支持完整元信息对象、键值字典与纯 Base64 字段三种结构，支持格式转码（PNG / WebP / JPEG）、尺寸限制、压缩质量调整与前缀开关。
   - **像素矩阵**：将图片采样编码为量化调色板矩阵（`type: "pixel-grid"`），体积紧凑可读且支持无损像素级还原。
   - 默认折叠预览超长 Base64 文本，取消折叠后自动换行方便手动框选；复制、下载与跨页签发送均保持完整数据。

3. **JSON 转图片**
   - **解码还原图片**：支持完整 JSON、单行键值对（`"dataUrl": "data:image/..."`）、直接粘贴 `data:image/...;base64,...`、常见图片魔数裸 Base64 字符串以及 `pixel-grid` 像素矩阵，支持棋盘格/浅色/深色画布、缩放预览、复制图片与单张/批量下载。
   - **渲染 JSON 图卡**：将任意 JSON 渲染为 `2x` / `3x` 高清语法高亮 PNG 图卡，提供森系浅纸、深松暗夜与石板冷灰三套图卡主题。

## 导入方式

在轻匣主界面点击「添加工具」，选择本目录中的 `plugin.json` 即可导入使用。更新插件文件后需在轻匣中重新导入。
